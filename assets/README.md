# Assets

Source art that is not generated from code.

- `clothing/solid-3500-budget/` - 39 solid-colour Roblox classic shirt and pants templates.
- `clothing/classic-50/` - 50 Roblox-ready classic clothing templates.

Zips of these were kept beside them in the project root; they were byte-identical copies and are
gone. Zips are ignored (see `.gitignore`): keep the unpacked folder here instead.
