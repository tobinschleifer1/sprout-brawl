# Blender assets — not started

The web build uses procedurally built placeholder rigs (`../web/src/render/rigs.js`), so no Blender work is needed to play it.

When the Roblox port begins, this folder holds the character and stage `.blend` files and the FBX exports, following
design document section 4 (`../docs/sprout-brawl-design.html`): 1 Blender unit = 1 stud, 4k–8k triangles per character,
R15-named skinned rigs with extra chain bones for vines and caps, and twenty clips per character at 60 fps.
